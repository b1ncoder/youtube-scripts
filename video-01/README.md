## 视频简介（草稿）
这期视频分享两件事：
1. 用很低的成本，长期保留一个爱沙尼亚 eSIM 号码（接收验证码、保号）；
2. 用一个手机端自动化脚本，自动完成 App 里重复的弹窗答题任务，换取免费的英国流量。

📂 本视频用到的脚本：AutoTouch_Mobile.js（AutoX.js 无障碍服务脚本）
🔗 脚本下载：见置顶评论 / 本仓库

【使用步骤】
1. 手机安装 AutoX.js，并开启无障碍服务与悬浮窗权限
2. 导入 AutoTouch_Mobile.js 并运行，点悬浮窗按钮开始
3. 打开对应 App 的任务列表，脚本会自动完成任务
4. 需要清零统计时，点悬浮窗里的「重置任务」
